Generates {"your text"|filter}. Useful to pass a fixed label through a filter (e.g. a link label for a URL stored elsewhere).
Syntax reference
{field} — simple value
{field|upper} — with filter
{field|badge:color=white,bg=primary} — filter with params
{field|default:value=N/A} — fallback for empty fields
{field|truncate:length=100|upper} — chained filters
{nested.child.value} — nested object access
{list[0].name} — array element access
